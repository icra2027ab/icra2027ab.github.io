For each pair choose the most appropriate distance type:
  - "centroid": Euclidean distance between the 3-D centroids of the two entities.
  - "surface": Shortest distance between the surfaces of the two entities (useful when contact/proximity matters).
  - "orientation": Projection of a body-frame vector of the end-effector onto a world-space reference direction. By default the tracked vector is the gripper's body z-axis (its "approach direction"), but you can set "ee_vector" to any body-frame direction (e.g. [1,0,0] for the gripper x-axis). Use when the orientation of the end-effector matters — e.g. ensuring the gripper approaches a target from above rather than from the side. Both "from_entity" and "to_entity" must be "ee" (the pair self-references). Requires either "axis" or "plane" (see below).
  - "gripper_aperture": Scalar gripper opening (metres). Both entities must be the gripper fingers — set "from_entity": "gripper_l" and "to_entity": "gripper_r".

Additionally, any pair can include at most ONE of the following optional component selectors to restrict the measurement to a subspace:
  - "axis" [x,y,z]: For positional pairs (centroid/surface), signed 1-D projection of the distance vector onto this direction — e.g. axis=[0,0,1] for vertical clearance during a lift, axis=[1,0,0] for progress along X during an approach. For "orientation" pairs, signed cosine of the angle between the tracked body vector and this direction (in [-1, 1]) — e.g. axis=[0,0,-1] gives +1 when the body vector points straight down ("approach from above") and -1 when it points straight up.
  - "plane" [nx,ny,nz]: For positional pairs, magnitude of the in-plane component after removing the contribution along this normal (2-D). Use for lateral alignment — e.g. plane=[0,0,1] gives XY-plane distance. For "orientation" pairs, magnitude of the tracked body vector projected into the plane perpendicular to the normal (in [0, 1]) — e.g. plane=[0,0,1] is 0 when the body vector is exactly vertical and 1 when it is fully horizontal.
  - "ee_vector" [x,y,z]: Only for "orientation" pairs. Specifies which body-frame direction of the end-effector to track. Defaults to [0,0,1] (z-axis, the "approach direction"). Set to [1,0,0] to track the gripper x-axis, [0,1,0] for the y-axis, or any arbitrary body-frame direction. Useful when the task cares about a sideways alignment rather than approach direction — e.g. pouring, where the gripper's x-axis must point away from the target container, or wiping, where the gripper's y-axis must remain aligned with the travel direction.

Set both "axis" and "plane" to null when the full 3-D distance is the right signal (positional pairs only — "orientation" pairs always need one).
