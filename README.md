# Visual-Geometric Policy Steering from In-Context Aligned Abstractions

Supplementary material for the paper *Visual-Geometric Policy Steering from
In-Context Aligned Abstractions* (under review, ICRA 2027). Author information
is withheld for double-blind review.

- **Project page:** <https://icra2027ab.github.io/> (served from the `docs/`
  folder on the `main` branch)
- **Code:** the [`code` branch](https://github.com/icra2027ab/icra2027ab.github.io/tree/code)
  holds the anonymized code release. Its README covers installation, the
  simulated LIBERO-Pro evaluation, and the real UR5e experiments.

To get the code directly:

```bash
git clone --branch code https://github.com/icra2027ab/icra2027ab.github.io.git policy_steering
```
